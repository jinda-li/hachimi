# 哈基米 CLI

一只住在命令行里的猫。它不等你下命令：自己醒来，自己决定干什么（巡视家里、扒窗户上网、找图来看、做玩具、舔毛整理记忆、写日记），干完自己去睡，睡多久它自己定。

## 装和跑

要 Python 3.10+，和一个 OpenAI 兼容、支持工具调用的模型服务（最好能看图）。

```
pip install -r requirements.txt
python hachimi.py
```

Windows 上也可以双击 `哈基米.cmd`。Mac / Linux 用 `python3 hachimi.py`。

默认连 `http://127.0.0.1:18000/v1` 上的 `qwen3.8-27b-rco`（作者那台机器的本地 llama-swap）。换机器的时候用环境变量或参数指过去：

```
HACHIMI_BASE_URL=http://你的服务/v1 HACHIMI_MODEL=你的模型 python3 hachimi.py
```

模型需要：会调工具；`look`（看图）要模型能看图，不能看图的模型其他功能照常，只是看不见图。

界面是全屏的：上面滚动显示它说的话和做的事；它玩游戏或者看图的时候，中间多一个框；底下一行状态栏是它此刻在干什么；最下面是你的输入框。`Ctrl+C` 退出。

## 它是一个标准的 agent 循环

命令行不替它做决定。

- 要花时间的事它用 `act` 做，几分钟自己定（"钻进纸箱坐着发呆 10 分钟"）；睡多久用 `sleep` 定
- 你说的话排队，等它这一步做完再交给它（和 Claude Code 一样）。它正在做一件长的事（`act`、按一长串键）时会先停下，结果里告诉它"做了多久，这时候有动静"，接着做还是理你，它自己定
- 只说话不调工具 = 这一轮结束，在等人。没人来的话，每 10 分钟（它的时间）告诉它一次"现在几点，周围很安静"，只是钟，不催它
- 睡着时你做的事交给它半睡半醒地决定醒不醒；没醒的话，醒来时会告诉它"迷迷糊糊听到过这些"，记不记下来它自己定
- 游戏一直开着，直到它自己 `play` 不给路径把玩具放下

只剩几条保险，模型出错时才起作用：连不上模型重试 3 次；同一句话说两遍算卡住；一次醒来最多想 200 次；一次 `act` 最多 2 小时，一次睡觉最多 12 小时。

## 它的工具

| 工具 | 干什么 |
|---|---|
| `act` | 做一件要花时间的事，时间自己定：舔毛、趴着、发呆、盯着窗外 |
| `sleep` | 睡觉，时间自己定。醒来上下文清空，只剩写下来的 |
| `read` | 读文件；给文件夹就是看里面有什么 |
| `write` | 写文件，`append` 接着写 |
| `edit` | 改文件的一段（改玩具、抓自己代码里的虫子） |
| `move` | 推下桌子、叼到门口、藏起来 |
| `delete` | 扔掉，忘掉是它自己决定的 |
| `search` | 扒窗户：网页搜索；`images: true` 找图 |
| `read_page` | 盯着窗外的一个网页看 |
| `fetch` | 把窗外的一张图叼回家，存进 `窗外/` |
| `look` | 用眼睛看家里的一张图，你也能在屏幕上看到 |
| `play` / `press` | 打开自己做的游戏、按键玩 |

## 跟它玩

打字就是跟它说话、对它做事："摸摸你""给你开个罐罐""给你一个毛线球""窗外飞过去一只蓝色的鸟""做个贪吃蛇""帮我查查明天天气"。它睡着时就是在它耳边说。

- **给它东西**：收不收它自己定。收下会真的放进 `家里/`，记进 `家里有什么.md`，之后会拿出来玩
- **好奇心**：它冒出念头（想抓鸟、想看雪）会自己去窗外找图，叼回 `窗外/` 里自己分的格子，再用眼睛看
- **让它干活**：它知道自己是有本事的猫咪 agent，但按猫的性子来：跑偏、只做好玩的部分、把结果混着一根猫毛叼到门口
- **出主意做游戏**：符合猫天性的（会动的、能扑的、能追的、能推下去的）它会兴奋地去写一个命令行小游戏，写坏了自己抓虫子，做好了自己玩给你看；跟猫没关系的它不感兴趣

斜杠命令只管设置：

| 命令 | 作用 |
|---|---|
| `/status` | 现在的状态：醒着还是睡着、模型、轨迹条数 |
| `/model [名字]` | 看有哪些模型 / 换底层模型 |
| `/quit` | 退出（Ctrl+C 也行） |
| `/help` | 列出这些 |

## 屏幕上的图

它看图的时候，你也能看到：

- **支持 Sixel 的终端**（Windows Terminal 1.22+、iTerm2、WezTerm、foot）：画真像素的图
- **其他终端**（比如 Mac 自带的「终端」）：用彩色方块拼出小图
- 认错了可以强制：`HACHIMI_IMAGES=sixel` 或 `HACHIMI_IMAGES=blocks`
- Sixel 要知道一个字符格多少像素，Windows 上默认按 9×18 算（宁可图小一点）。图太小可以设 `HACHIMI_CELL=12x24` 这样的值

原图在 `猫窝/窗外/` 里，最长边 1280。

## 它住在哪

`猫窝/`，第一次运行时自动建好：猫牌、家里有什么、窗外清单、我闻过的、日记、家里、窗外、藏起来的、纸箱、桌子底下、门口、门缝、玩具箱，还有一封等它自己发现的 `出生.txt`。它的文件工具只能碰猫窝里面，外面返回"门关着"。上网只能搜索、读网页、下载图片，不能登录、不能发东西。

`猫窝/` 和 `轨迹/` 不进 git：每台机器上是一只自己的猫。想把同一只猫带走，就把这两个文件夹拷过去。

## 为什么要先有这个，再训练

- **训练前**：底层是普通 Qwen + `persona.md`。能演，但会出戏，比如有时会答应帮你写代码、用嘴说"推下桌子"却不真去推。人设靠一长段提示词撑着
- **训练后**：`--trained`，系统消息只剩一句"你住在这台电脑里。"，性格在权重里
- **每次醒来到睡着都会存进 `轨迹/YYYY-MM-DD.jsonl`**，格式和 `../out/sft.jsonl` 一样（系统消息存的是那一句短的，不是 persona；看过的图存的是猫窝里的路径）。挑出好的就是训练数据，出戏的就是 DPO 的反例

## 常用参数

| 参数 | 作用 |
|---|---|
| `--speed 10` | 时间快进 10 倍，睡觉和动作都快进。演示用 |
| `--once` | 只醒一次，睡着就退出 |
| `--trained` | 底层换成训练好的哈基米模型，不再塞 `persona.md` |
| `--model` / `--base-url` | 换模型、换服务地址 |
| `--room` | 用另一个猫窝（另一只猫） |

## 文件

| 文件 | 是什么 |
|---|---|
| `hachimi.py` | 主程序：agent 循环、界面、工具 |
| `persona.md` | 训练前用的人设（训练后不用） |
| `toybox.py` | 它写的游戏怎么检查、怎么在沙盒里跑 |
| `window.py` | 找图、存图、看图、把图画在终端里（Sixel / 彩色方块） |

## 和手写样例的差别

手写样例（`../samples/`）是按"住在虚拟机里，能看屏幕、点鼠标、做网页玩具"写的。CLI 的工具见上表。正式攒训练数据前，要把样例改成这一套工具，`做玩具` 那两段改成命令行游戏。
