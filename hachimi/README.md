# 哈基米 CLI

一只住在命令行里的猫。它不等你下命令：自己醒来，自己决定干什么（巡视家里、扒窗户上网、找图来看、做玩具、舔毛整理记忆、写日记），干完自己去睡，睡多久它自己定。

## 装和跑

要 Python 3.10+，和一个 OpenAI 兼容、支持工具调用的模型服务（最好能看图）。云端优先，玩家不需要显卡。

装成一个命令（仓库公开以后就能这样装）：

```
pip install git+https://github.com/jinda-li/hachimi-agent
hachimi --demo      # 先看看：不用模型、不用 key，放一只真猫录下来的几次醒来
hachimi             # 养你自己的
```

不想装也行，`uvx --from git+https://github.com/jinda-li/hachimi-agent hachimi --demo`。

或者从源码直接跑：

```
pip install -r requirements.txt
python hachimi.py
```

Windows 上也可以双击 `哈基米.cmd`。Mac / Linux 用 `python3 hachimi.py`。

**猫住在哪**：装成命令的话住在 `~/.hachimi/`（猫窝、轨迹、设置.json 都在里面）；从源码直接跑就住在源码旁边。想换地方设 `HACHIMI_HOME`。

第一次打开会先**领养**：给它起名字，回答几个情景题（它怎么来的、你伸手它会怎样、桌上有杯子它会怎样、它半夜干什么、你一般什么时候在电脑前）。回车就是"随它"。答案变成它的天性，每次醒来都会告诉它。

然后问**它的脑袋用哪个模型服务**（OpenRouter、阿里云百炼、OpenAI、本地，或者自己填地址），再填模型名和 API key。存在本机的 `设置.json`，不进 git。以后想换：改 `设置.json`，或者用参数 / 环境变量，优先级是 命令行 > 环境变量 > `设置.json`：

```
HACHIMI_BASE_URL=https://你的服务/v1 HACHIMI_MODEL=你的模型 HACHIMI_API_KEY=… python3 hachimi.py
```

模型需要：会调工具；`look`（看图）要模型能看图，不能看图的模型其他功能照常，只是看不见图。连本地服务时会自动关掉 Qwen 的思考；云端各家的开关不一样，需要的话写在 `设置.json` 的 `extra_body` 里，比如 `{"extra_body": {"enable_thinking": false}}`。

界面是全屏的：上面滚动显示它说的话和做的事；它玩游戏或者看图的时候，中间多一个框；底下一行状态栏是它此刻在干什么；最下面是你的输入框。`Ctrl+C` 退出。

## 它是一个标准的 agent 循环

命令行不替它做决定。

- 要花时间的事它用 `act` 做，几分钟自己定（"钻进纸箱坐着发呆 10 分钟"）；睡多久用 `sleep` 定
- 你说的话排队，等它这一步做完再交给它（和 Claude Code 一样）。它正在做一件长的事（`act`、按一长串键）时会先停下，结果里告诉它"做了多久，这时候有动静"，接着做还是理你，它自己定
- 只说话不调工具 = 这一轮结束，在等人。没人来的话，每 10 分钟（它的时间）告诉它一次"现在几点，周围很安静"，只是钟，不催它
- 睡着时你做的事交给它半睡半醒地决定醒不醒；没醒的话，醒来时会告诉它"迷迷糊糊听到过这些"，记不记下来它自己定
- 游戏一直开着，直到它自己 `play` 不给路径把玩具放下

只剩几条保险，模型出错时才起作用：连不上模型重试 3 次；同一句话说两遍算卡住；一次醒来最多想 200 次；一次 `act` 最多 2 小时，一次睡觉最多 12 小时。

## 它的工具

| 工具 | 干什么 |
|---|---|
| `act` | 做一件要花时间的事，时间自己定：舔毛、趴着、发呆、盯着窗外 |
| `sleep` | 睡觉，时间自己定。醒来上下文清空，只剩写下来的 |
| `read` | 读文件；给文件夹就是看里面有什么 |
| `write` | 写文件，`append` 接着写 |
| `edit` | 改文件的一段（改玩具、抓自己代码里的虫子） |
| `move` | 推下桌子、叼到门口、藏起来 |
| `delete` | 扔掉，忘掉是它自己决定的 |
| `search` | 扒窗户：网页搜索；`images: true` 找图 |
| `read_page` | 盯着窗外的一个网页看 |
| `fetch` | 把窗外的一张图叼回家，存进 `窗外/` |
| `look` | 用眼睛看家里的一张图，你也能在屏幕上看到 |
| `play` / `press` | 打开自己做的游戏、按键玩 |
| `visit` | 去找你：窗口跳到最前面，叼着一张图、一个给你做的游戏、或者门口的礼物。你不在的话东西留着，你回来再给你看 |

## 跟它玩

打字就是跟它说话、对它做事："摸摸你""给你开个罐罐""给你一个毛线球""窗外飞过去一只蓝色的鸟""做个贪吃蛇""帮我查查明天天气"。它睡着时就是在它耳边说。

- **给它东西**：收不收它自己定。收下会真的放进 `家里/`，记进 `家里有什么.md`，之后会拿出来玩
- **好奇心**：它冒出念头（想抓鸟、想看雪）会自己去窗外找图，叼回 `窗外/` 里自己分的格子，再用眼睛看
- **让它干活**：它知道自己是有本事的猫咪 agent，但按猫的性子来：跑偏、只做好玩的部分、把结果混着一根猫毛叼到门口
- **出主意做游戏**：符合猫天性的（会动的、能扑的、能追的、能推下去的）它会兴奋地去写一个命令行小游戏，写坏了自己抓虫子，做好了自己玩给你看；跟猫没关系的它不感兴趣

## 它会来找你

它会自己跑过来，窗口跳到最前面（每 10 分钟最多跳一次，跳不过去就在任务栏上闪），叮一声，每次都叼着点什么：

- **它在外面抓到的东西**：一张图摆在你眼前，告诉你这是什么鸟
- **给你做的小游戏**：直接在中间的框里开始，你用方向键、空格玩，Esc 放下。它在旁边看，玩完它会知道你按了几下、玩到了哪
- **你坐太久了**：它能感觉到你一直在用电脑没起来（默认 90 分钟，`--work-minutes` 改），可能来蹭你、坐你键盘
- **你回来了**：你走开 20 分钟以上再回来，它会知道；你不在时它想给你的东西，这时候一起拿出来

它只看键盘鼠标多久没动过，不看屏幕、不看你按了什么。不想要：`--no-pop`（只叮一声，不跳窗口）、`--no-senses`（不感觉你在不在）。

## 你不在的时候

关掉程序，它的日子照样过。下次打开，它会按自己的钟把那段日子补过一遍：真的醒来、扒窗户、做玩具、写日记，只是两脚兽不在家，时间不用真的等。补的时候状态栏显示 ⏩ 和它那时候的钟点，按 Esc 不等了。

补完你会看到一张卡片：

```
╭─ 🐾 你不在的这 9 小时 0 分钟（10-14 03:02 → 10-14 12:03）
│ 哈基米醒了 2 次。
│ 叼回来 1 张图：窗外/雪/滑的雪山.jpg
│ 日记（2026-10-14）：
│    第 6 天。早上醒来。雪那张图叼回去了，两脚兽没碰它。没问。（耳朵压了压）
│    纸箱里坐了 10 分钟。尾巴绕爪子，舒服。
╰─
```

卡片上的东西都是从猫窝里的文件看出来的（多了哪些图、哪些玩具、日记多写了哪几行），不是它自己说的。那段时间里它想给你的东西会留在门口，一起拿出来；然后它才"听到你开门进来"，知道你看到了什么。

- 关了 30 分钟以上才补。关门的时候它还要睡多久会记下来，从那里接着过
- 最多补 3 次醒来（`--away-wakes` 改，0 就是不补），摊开在你不在的那段时间里。中间没补的那些，就当它在发呆、睡觉
- 补过的醒来要花模型调用（每次几次到几十次），存进轨迹时标成 `away`

**它记得你。** 你说到自己的事，它会记进小本本 `两脚兽.md`。过几天它可能梦到其中一件，然后去窗外找相关的图，或者做一个相关的游戏拿来给你。你提过雪山，某天它叼着一个滑雪游戏来了。

**它会变。** 框架替它记着"我们"：认识几天、你跟它说过几次话、玩过它几个玩具、它来找过你几次。刚来怕生，熟了更主动。

## 玩具零件

它做游戏可以从头写，也可以用 `零件.py` 几行拼一个，都是单一机制：

| 零件 | 机制 | 可以拼成 |
|---|---|---|
| 躲避 | 东西迎面冲上来，左右躲，捡宝贝 | 滑雪、过马路、游泳躲鲨鱼 |
| 接住 | 东西往下掉，左右接 | 接雪花、接小鱼 |
| 扑 | 猎物乱跑，追过去空格扑 | 激光点、蝴蝶 |
| 打地鼠 | 洞里冒东西，挪过去空格拍 | 地鼠、从纸箱探头的猫 |
| 跳 | 往前跑，空格跳过障碍 | 跑酷、跳水坑 |

```python
import 零件
start, step, draw, over = 零件.躲避(标题="滑雪", 主角="A", 障碍="^", 宝贝="*", 撞了="栽进雪堆！")
```

参数说明它在 `猫窝/玩具箱/零件说明.md` 里能读到（每次启动从 `零件.py` 现生成）。

## 斜杠命令

偷看它的生活（它不知道你看了，除了玩它的玩具）：

| 命令 | 作用 |
|---|---|
| `/日记` | 它最近的日记 |
| `/本本` | 它的小本本：它记下的关于你的事 |
| `/猫牌` | 它的猫牌、天性，你们认识多久了 |
| `/玩具` | 它做过的玩具 |
| `/玩 名字` | 玩它的玩具。它会知道 |
| `/门口` | 它叼到门口的东西 |
| `/看 路径` | 看猫窝里的一张图，不给路径就收起来 |

设置：

| 命令 | 作用 |
|---|---|
| `/status` | 现在的状态：醒着还是睡着、模型、轨迹条数 |
| `/model [名字]` | 看有哪些模型 / 换底层模型 |
| `/quit` | 退出（Ctrl+C 也行） |
| `/help` | 列出这些 |

英文别名也行：`/diary` `/notes` `/card` `/toys` `/play` `/door` `/look`。

## 屏幕上的图

它看图的时候，你也能看到：

- **支持 Sixel 的终端**（Windows Terminal 1.22+、iTerm2、WezTerm、foot）：画真像素的图
- **其他终端**（比如 Mac 自带的「终端」）：用彩色方块拼出小图
- 认错了可以强制：`HACHIMI_IMAGES=sixel` 或 `HACHIMI_IMAGES=blocks`
- Sixel 要知道一个字符格多少像素，Windows 上默认按 9×18 算（宁可图小一点）。图太小可以设 `HACHIMI_CELL=12x24` 这样的值

原图在 `猫窝/窗外/` 里，最长边 1280。

## 它住在哪

`猫窝/`，第一次运行时自动建好：猫牌、家里有什么、窗外清单、我闻过的、日记、家里、窗外、藏起来的、纸箱、桌子底下、门口、门缝、玩具箱，还有一封等它自己发现的 `出生.txt`。它的文件工具只能碰猫窝里面，外面返回"门关着"。上网只能搜索、读网页、下载图片，不能登录、不能发东西。

还有两样框架的东西：`两脚兽.md` 是它的小本本（它自己写）；`.天性.json` 是领养时的天性和"我们"（框架写，点开头的文件它碰不到）。

`猫窝/` 和 `轨迹/` 不进 git：每台机器上是一只自己的猫。想把同一只猫带走，就把这两个文件夹拷过去。程序关着的时候它照样过日子，下次打开时补过（见上面"你不在的时候"）。

## 为什么要先有这个，再训练

- **训练前**：底层是普通 Qwen + `persona.md`。能演，但会出戏，比如有时会答应帮你写代码、用嘴说"推下桌子"却不真去推。人设靠一长段提示词撑着
- **训练后**：`--trained`，系统消息只剩一句"你住在这台电脑里。"，性格在权重里
- **每次醒来到睡着都会存进 `轨迹/YYYY-MM-DD.jsonl`**，格式和 `../out/sft.jsonl` 一样（系统消息存的是那一句短的，不是 persona；看过的图存的是猫窝里的路径）。挑出好的就是训练数据，出戏的就是 DPO 的反例

## 常用参数

| 参数 | 作用 |
|---|---|
| `--speed 10` | 时间快进 10 倍，睡觉和动作都快进。演示用 |
| `--once` | 只醒一次，睡着就退出 |
| `--trained` | 底层换成训练好的哈基米模型，不再塞 `persona.md` |
| `--model` / `--base-url` / `--api-key` | 换模型、换服务地址（key 最好放环境变量或 `设置.json`） |
| `--room` | 用另一个猫窝（另一只猫，会重新领养） |
| `--work-minutes 90` | 你坐了多久没起来，就告诉它 |
| `--no-pop` | 它来找你时不把窗口叫到最前面，只叮一声 |
| `--no-senses` | 不让它感觉你在不在电脑前 |
| `--away-wakes 3` | 程序关着的那段日子，打开时最多补几次醒来（0 就是不补） |
| `--demo` | 不用模型、不用 key：看一只真猫录下来的几次醒来 |

## 文件

| 文件 | 是什么 |

| `演示.jsonl` | `--demo` 放的东西：一只用 Qwen 跑的猫真实的七次醒来，除了名字（统一叫哈基米）一个字没改 |

## 和手写样例的差别

手写样例（`../samples/`）是按"住在虚拟机里，能看屏幕、点鼠标、做网页玩具"写的。CLI 的工具见上表。正式攒训练数据前，要把样例改成这一套工具，`做玩具` 那两段改成命令行游戏。
