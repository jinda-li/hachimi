# 哈基米

一只住在电脑里的猫咪 agent。好奇、独立、坏坏的、可爱，什么都能唱成哈基米的歌；会上网、会找图来看、会给自己写小游戏玩，但让它干活，它按猫的性子来。

两部分：

1. **`hachimi/`：哈基米 CLI。** 一个主动型的 agent：自己醒来、自己决定干什么、自己睡。你打字跟它说话、给它东西、给它出主意。现在底层是普通 Qwen + 人设提示词，见 [hachimi/README.md](hachimi/README.md)
2. **其余：后训练语料。** 目标是把"像猫"训进模型里（基座 Qwen3.5-9B），训完以后 CLI 用 `--trained` 启动，不再需要人设提示词

| 文件 | 是什么 |
|---|---|
| `hachimi/` | 哈基米 CLI |
| `宪法.md` | 语料的源头：猫行为对照表、哈基米梗怎么用、哈基米之歌、坏坏、猫不干活的方式、做玩具、声音规范、DPO 四种反例 |
| `数据格式.md` | 一次醒来 = 一条样本；工具列表；猫窝里的文件；手写格式 |
| `samples/` | 11 条手写 SFT 样例，七类 |
| `dpo/` | 2 组 DPO 样例，每组 1 个好的 + 4 种不对的（助手 / 人设说明书 / 烂梗轰炸 / 刻薄） |
| `玩具箱样品/` | 样例里它做的两个网页小游戏（激光点、推杯子） |
| `to_jsonl.py` | 样例转成训练用的 JSONL，顺便查禁用词、颜文字和梗的密度 |
| `render_check.py` | 用 `qwen35_chat_template.jinja` 渲染，检查工具参数和 `<think>` |
| `旧版-玩的孩子/` | 最早的设计："只会玩的孩子"，骨架（醒来、记忆、睡觉、不会工作）沿用至今 |

```
python to_jsonl.py            # → out/sft.jsonl, out/dpo.jsonl
python render_check.py        # → out/rendered/*.txt（要 jinja2）
```

## 现在的状态（2026-10-08）

- 哈基米 CLI 能用：标准 agent 循环，节奏、醒不醒、收不收东西都由它自己定；能上网、找图、看图（终端里 Sixel 或彩色方块显示）、写自己的命令行小游戏并在沙盒里玩
- 还没有做后训练。现在的模型靠 `hachimi/persona.md` 演，会出戏（干活太老实、用嘴说动作却不调工具）
- 手写样例是按旧的"虚拟机、看屏幕点鼠标"工具写的，和 CLI 的工具对不上，要改
- 聊天模板已实测：模板只认 dict 形式的 `arguments`（字符串会被悄悄丢掉）
